# Project context

Attribution Intelligence Studio is a static React portfolio demo. The initial app was added to this repository on 2026-05-06. It explores how growth and RevOps teams might compare channel contribution, attribution models, experiment scenarios, and workflow alerts in one interface.

All figures and decisions are synthetic, hand-authored examples. The repository does not ingest event streams, process customer data, calculate statistical confidence, or implement production attribution logic. Its value today is the interface and information design, not a validated business outcome.

The next meaningful product step would be to define real source contracts and metric methodology before adding live data. That work would need provenance, consent and privacy review, reconciliation rules, and a testable decision model.
